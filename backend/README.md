# LinkList Backend

Backend uygulaması bu klasörde geliştirilecektir.

## Sorumluluklar

- Kullanıcı ve profil yönetimi
- Liste CRUD işlemleri ve görünürlük yetkileri
- Ürün CRUD işlemleri
- Linkten ürün bilgisi çıkarma ve manuel tamamlama
- Favori, takip ve listeye kaydetme işlemleri

Frontend'in beklediği sözleşme için `../docs/api-contract.md` dosyasını güncel tutun.
